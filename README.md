# vanya_ctf_superfarm — комплект команды на финал InnoCTF Junior (Attack-Defense)

Всё **наше** для игры в одном репозитории: скрипты установки и защиты,
клиент жюри, шаблоны сплойтов, ферма (полный исходник — правим прямо
здесь) и раздача сплойтов. Клоны машин команды качают только этот репо —
он самодостаточен для дня игры.

```bash
git clone https://github.com/Iam-Mil/vanya_ctf_superfarm.git
cd vanya_ctf_superfarm

# НА ИГРЕ (машина «только git + apt», Docker Hub закрыт):
sudo bash offline.sh      # поставит docker/compose из apt, образы из images/,
                          # поднимет ферму БЕЗ Docker Hub / PyPI / npm

# ДОМА (полный интернет — необязательно, то же самое, но с нуля):
sudo bash install.sh
```

## Карта репозитория

| Путь | Что это | Когда нужно |
|---|---|---|
| `PLAYBOOK.md` | **главный план игры**: параметры, сеть, роли, таймлайн | прочитать до старта |
| `DOCKER.md` | **docker: все сценарии установки** (Kali/Ubuntu/Debian/официальный) + лечение типовых ошибок | если docker не ставится |
| `FARM.md` | **ферма: вся настройка и работа по шагам** (конфиг, запуск, сплойты, ошибки) | у капитана + атакующие |
| `SPLOITS.md` | **сплойты: полный справочник** — классы уязвимостей, скелеты, запуск, таблица ошибок, отладка | атакующие — прочитать до игры |
| `CHEATSHEET.md` | шпаргалка команд | держать открытым на игре |
| `install.sh` | установка docker+софта на машину | при развёртывании |
| `secure.sh` | **пароли/SSH-ключи/чистка ключей по чек-листу оргов** (в корне, запускать на каждой машине) | сразу после получения доступа |
| `forcad/` | клиент API жюри + `thrower.py` (ручная сдача флагов) | атака/сдача |
| `sploits/template.py` | шаблон сплойта (совместим с фермой/neo) | первый сплойт |
| `farm/` | `gen_teams.py` (список команд из API жюри) + протокол-модуль | настройка фермы |
| `vulnbox/` | `harden.sh` + `inventory.sh` | первые 10 минут защиты |
| `kali/` | `setup_kali.sh` (прокси+софт+ключ+проверка жюри) | настройка Kali |
| `repos/S4DFarm/` | **ферма, полный исходник** — с протоколом `forcad_http` и конфигом под ForcAD | капитан, день игры |
| `tools/` | neo-клиенты (linux amd64/arm64) + исходник neo-сервера + конфиги-примеры | раздача сплойтов |

## День игры — 3 команды

1. **Настроить Kali**: `sudo bash kali/setup_kali.sh` (прокси, софт, ssh-ключ,
   проверка связи с жюри `http://10.10.10.10`).
2. **Капитан поднимает ферму** — `repos/S4DFarm`:
   - в `server/app/config.py` вписать `TEAM_TOKEN` (из письма), вставить
     `TEAMS` (генератор: `python3 farm/gen_teams.py` из корня репо), сменить
     `SERVER_PASSWORD`;
   - `docker compose up --build -d` → веб-морда на `http://<ip>:5137`.
3. **Раздача сплойтов** (по желанию): `tools/` — neo-сервер у капитана,
   neo-клиенты на Kali (конфиги-примеры рядом). Без него — `thrower.py`.

Подробно по минутам — `PLAYBOOK.md`.

## Ключевые факты под нашу игру (из письма оргов)

- Сеть: своя подсеть `10.2.X.0/24`, вулнбокс `10.2.X.2`; **весь трафик
  других команд приходит со шлюза `10.2.X.1`** — не банить его ни при каких
  условиях (там же, скорее всего, ходит чекер).
- Жюри: `10.10.10.10` (борда/API/сдача `PUT /flags` с заголовком
  `X-Team-Token`; лимиты: 2 запроса/сек на токен, ≤100 флагов за запрос).
- Раунд 2 мин, флаг живёт 5 раундов (10 минут), hardness 10 (~79 очков за
  кражу при равных силах), старт 2500.
- Интернет на месте — только через прокси `10.10.10.10:8080` (HTTP GET,
  allowlist) → **всё тяжёлое берём из этого репозитория, на месте не качаем**.
