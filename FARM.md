# FARM.md — ферма: настройка и работа, по шагам

Полный путь флага (запомни эту цепочку — всё остальное её детали):

```
сплойт печатает флаги в stdout
  → клиент фермы (start_sploit.py) подобрал их по regex
    → сервер фермы накопил
      → каждые 2 сек пачкой ≤100 отправил в жюри (PUT /flags + ваш токен)
        → жюри: Elo, first blood, борда
```

---

## 1. Как устроена ферма (три части)

| Часть | Где | Что делает |
|---|---|---|
| **Сервер** | `docker compose` (сервис `farm`) | хранит список команд, формат флага, пароль морды; копит флаги; **каждые 2 сек сдаёт их в жюри** через `protocols/forcad_http.py` (уже в репе) |
| **Клиент** | `client/start_sploit.py` (запускается руками на атакующей машине) | тянет у сервера список команд и regex; каждые N сек запускает **ваш сплойт против каждой команды**; читает stdout; флаги → на сервер |
| **Морда** | `http://<ip_капитана>:5137` | статистика: каждый флаг, его статус, от какого сплойта, с какой команды |

Сервер ходит в жюри **только он** — поэтому лимиты жюри (2 запроса/сек, ≤100 флагов) никогда не нарушаются, сколько бы атакующих машин ни было.

## 2. Настройка: каждое поле, по одному

Файл один: **`repos/S4DFarm/server/app/config.py`**. Что значит каждое поле и что туда ставить:

| Поле | Что это | НА ИГРЕ (10.10.10.10) | НА ЛАБЕ (репетиция) |
|---|---|---|---|
| `TEAM_TOKEN` | токен вашей команды — по нему жюри понимает, КТО сдаёт | из письма оргов | `6077e2b6cea881da` (Alpha; после `lab/reset.sh` меняется — см. `control.py print_tokens`) |
| `SYSTEM_URL` | куда сдавать флаги | `http://10.10.10.10/flags` | `http://127.0.0.1:8080/flags` (борда на той же машине) |
| `SYSTEM_PROTOCOL` | модуль сдачи | `forcad_http` (уже стоит) | то же |
| `TEAMS` | кого атаковать: `{'имя': 'ip'}` | из API жюри (см. ниже) | из API борды лаба |
| `FLAG_FORMAT` | regex для поиска флагов в выводе сплойтов | `r'[A-Z0-9]{31}='` (уже стоит) | то же |
| `SERVER_PASSWORD` | пароль морды и API фермы | свой пароль | свой пароль |
| `SUBMIT_FLAG_LIMIT`/`SUBMIT_PERIOD` | пачка/период сдачи | `100` / `2` — ровно под лимиты жюри, НЕ ТРОГАТЬ | то же |
| `FLAG_LIFETIME` | флаги старше не пересылаем | `10*60` — окно жизни флага (5 раундов × 2 мин), НЕ ТРОГАТЬ | то же |
| `TIMEZONE` | для отчётов по времени | `Europe/Moscow` | то же |

**Заполняем TEAMS одной командой** (генератор берёт список команд из API жюри):

```bash
# НА ИГРЕ:
GAME_URL=http://10.10.10.10 python3 farm/gen_teams.py
# НА ЛАБЕ:
GAME_URL=http://172.25.15.100:8080 python3 farm/gen_teams.py
```

Вывод — готовый словарь — вставить в config.py вместо пустого `TEAMS`. **И вычеркните из него свою команду**: свои флаги жюри не примет (`your own`), а сплойт будет зря тратить прогон.

## 3. Запуск фермы (у капитана)

```bash
cd repos/S4DFarm
echo 'SERVER_PASSWORD=придумай_пароль' > .env   # compose ждёт эту переменную
sudo docker compose up --build -d

# проверка:
sudo docker compose ps         # farm/celery/front/postgres/redis — все Up
# морда:  http://<ip_этой_машины>:5137   (пароль — из .env)
```

**Изменил config.py → перезапусти так:**
```bash
sudo docker compose up -d --force-recreate farm celery
```

## 4. Прогнать сплойт через ферму (первый раз)

Сплойт — любой скрипт, который запускается как `sploit.py <ip команды>` и печатает флаги в stdout. Свои кладите, например, в `repos/S4DFarm/client/sploits/`.

```bash
cd repos/S4DFarm/client
mkdir -p sploits && cp /путь/к/моему_сплойту.py sploits/
chmod +x sploits/моему_сплойту.py

python3 start_sploit.py sploits/моему_сплойту.py \
    --server-url http://127.0.0.1:5137 \
    --server-pass <пароль_из_.env>
```

Что увидишь:
- **в терминале клиента**: циклы «Attacking team X → вывод сплойта → Got N flags» каждые ~55 c;
- **в морде**: флаги со статусами — `Accepted` (очки идут), плюс нормальные для обучения отвергнутые: `your own` (свой флаг), `already stolen` (дубликат — на лабе все команды на одном IP);
- **на борде жюри**: ваша команда растёт, жертвы падают.

`Ctrl+C` — остановить атаку.

## 5. Ручки клиента

| Флаг | Значение |
|---|---|
| `--server-url` | адрес морды фермы (у капитана) |
| `--server-pass` | пароль из `.env` |
| `--attack-period N` | период атаки: **110–115 на игре** (раунд 120 c), 55 на лабе (раунд 60 c) |
| `-v N` | показать вывод сплойтов первых N циклов (диагностика) |
| `--not-per-team` | один прогон вместо прогона на каждую команду |
| `--distribute K/N` | работать только над K-й из N частей списка команд — для нескольких машин (см. §6) |
| `--pool-size N` | параллелизм (50 по умолчанию, не трогать) |
| `-e` | сплойты без таймаутов (осторожно) |

## 6. Несколько атакующих машин

**Без neo (просто):** на трёх Kali запускаете один и тот же клиент с разными долями:
```bash
python3 start_sploit.py sploits/x.py --server-url http://<капитан>:5137 --server-pass ... --distribute 1/3
python3 start_sploit.py sploits/x.py ... --distribute 2/3
python3 start_sploit.py sploits/x.py ... --distribute 3/3
```

**С neo (автоматически):** сервер neo сам делит команды между клиентами и раздаёт новые версии сплойтов — настройка в `tools/` (конфиги-примеры рядом), подробно в `PLAYBOOK.md`.

## 7. Если что-то не так (симптом → лечение)

| Симптом | Причина и что делать |
|---|---|
| Клиент: `server did not respond` | неверные `--server-url`/`--server-pass`, или ферма не поднята: `docker compose ps` |
| Флаги в морде есть, все отвергнуты | смотри ответ жюри в морде: `your own` → вычеркни свою команду из TEAMS; `invalid` → TEAM_TOKEN неверен; `Game is not available` → игра ещё не началась на борде |
| Флагов в морде нет вообще | сплойт ничего не печатает — запусти его руками `python3 sploit.py <ip>` и смотри stderr; либо FLAG_FORMAT не совпадает с реальным флагом |
| В морде "Rejected: too old" | `--attack-period` слишком большой — флаг протухает раньше, чем его сдали: уменьшай период |
| Сплойт падает на живых боксах, на локальном работал | лови исключения внутри сплойта (шаблон `sploits/template.py` уже это делает), смотри `-v 5` |

## 8. Чек-лист «что меняется на игре» (3 замены)

1. `config.py`: `TEAM_TOKEN` ← из письма; `SYSTEM_URL` ← `http://10.10.10.10/flags`; `TEAMS` ← `GAME_URL=http://10.10.10.10 python3 farm/gen_teams.py` (себя вычеркнуть).
2. Цели сплойтов — IP вулнбоксов `10.2.Y.2`.
3. `--attack-period 110`–`115`.

Всё остальное — идентично репетиции.

## 9. Это ваш форк фермы — как вносить правки

Правите код фермы (например, `protocols/forcad_http.py` или логику сервера):

```bash
git add -A && git commit -m "что поменял" && git push
# на остальных машинах: git pull
# применить на капитане: sudo docker compose up -d --force-recreate farm celery
```

Так же раскатывайте новые сплойты на все машины: push в репо → pull → перезапуск клиента (или через neo — тогда ничего копировать не надо).
